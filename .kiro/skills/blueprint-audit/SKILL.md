# Blueprint Audit

Produce a matrix:

Domain | Skill | Topics | Flashcards | Practice Questions | Exam Questions | Coverage

Identify:
- missing skills
- underrepresented skills
- overrepresented skills
- orphan content
- skills without assessment
- skills without learning content

Do not invent blueprint requirements. Use the project's structured blueprint and authoritative sources.
