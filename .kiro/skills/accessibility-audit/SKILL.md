# Accessibility Audit

Review:
- keyboard navigation
- focus order
- focus visibility
- headings
- landmarks
- buttons/links
- forms
- dialogs
- flashcards
- quizzes
- timers
- status announcements
- color contrast
- reduced motion
- mobile touch targets

Prioritize actual user flows.

Report severity and concrete fixes.
