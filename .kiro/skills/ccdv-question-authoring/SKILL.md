# CCDV-F Question Authoring

Create original practice questions.

Each question must test a defined skill and have a defensible answer.

Prefer:
- application
- analysis
- evaluation
over trivial recall.

Distractors should represent realistic misconceptions, not jokes or obviously wrong answers.

Avoid:
- ambiguous wording
- double negatives
- trivia without learning value
- clues in option length
- "all of the above" unless pedagogically justified
- recalled/reconstructed exam questions

Every option should have an explanation when the schema supports it.

Assign:
- skill
- difficulty
- cognitive level
- source/evidence

Review questions adversarially before accepting them.
