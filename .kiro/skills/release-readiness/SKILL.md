# Release Readiness

Do not give a 10/10 merely because features exist.

Verify:
- requirements
- blueprint coverage
- content validation
- source provenance
- exam integrity
- typecheck
- lint
- unit tests
- integration tests
- E2E tests
- build
- accessibility
- performance
- security
- documentation
- changelog

For every issue below 9/10:
- identify evidence
- identify files
- explain impact
- propose fix

Final verdict:
SHIP / FIX / BLOCK
