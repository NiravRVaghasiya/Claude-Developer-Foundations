# Source Verification

For every factual claim:

1. Identify the claim.
2. Find the strongest authoritative source available.
3. Prefer official Anthropic documentation for Anthropic product/API behavior.
4. Verify that the source actually supports the claim.
5. Record source URL and verification date.
6. Flag unsupported or ambiguous claims.

Never manufacture citations.

When a source is unavailable or unclear, mark the claim `needs-review`.
