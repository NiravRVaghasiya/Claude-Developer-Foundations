# Performance Audit

Inspect:
- unnecessary client components
- hydration cost
- bundle size
- duplicate dependencies
- search indexing/runtime cost
- MDX rendering
- localStorage access
- image usage
- expensive re-renders

Prefer measured evidence over speculation.

Return:
- metric
- baseline
- issue
- recommendation
- expected impact
