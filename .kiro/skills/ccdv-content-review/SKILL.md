# CCDV-F Content Review

Inspect the content against the current structured exam blueprint and authoritative sources.

Check:
1. factual correctness
2. outdated claims
3. missing concepts
4. blueprint mapping
5. learning objectives
6. practical usefulness
7. common misconceptions
8. source quality
9. terminology consistency
10. exam-integrity compliance

Return:
- strengths
- critical issues
- medium issues
- minor issues
- recommended changes
- coverage status

Never invent facts to fill gaps.
