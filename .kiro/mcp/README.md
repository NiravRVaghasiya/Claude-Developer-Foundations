# MCP Recommendations

This project benefits most from:

1. Authoritative web/documentation access
2. Browser/Playwright automation for real UI verification
3. GitHub integration for repository and release workflows

Do not add database or cloud infrastructure MCPs unless the product requirements change.

Never commit API keys.

Use your Kiro MCP configuration UI or workspace MCP settings to install servers appropriate to your environment.

The included `settings/mcp.json.example` only enables Kiro's built-in Fetch MCP and contains no credentials.
