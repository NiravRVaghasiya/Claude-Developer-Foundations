# Content Quality Contract

Educational content is production data.

Every factual learning unit should have:
- blueprint skill mapping
- source/evidence
- verification date where applicable
- difficulty
- clear learning objective

Every practice question should have:
- stable ID
- skill mapping
- difficulty
- cognitive level
- valid answer mapping
- explanation for every option where appropriate
- evidence/source metadata

Never invent undocumented Anthropic behavior.

When uncertain, mark content as needs-review instead of guessing.

Prefer primary/official documentation for product behavior.
