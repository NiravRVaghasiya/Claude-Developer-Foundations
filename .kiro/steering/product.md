# Product Principles

This repository is an evidence-backed interactive CCDV-F preparation platform.

Optimize for learner outcomes, not feature count.

Priorities:
1. Correctness
2. Exam alignment
3. Learning effectiveness
4. Usability
5. Accessibility
6. Maintainability
7. Performance

Prefer extending the existing architecture over introducing new infrastructure.

Do not introduce a backend, authentication, database, analytics platform, or state-management framework unless a concrete product requirement justifies it.

Never claim that the application guarantees exam success or predicts actual pass probability.
